# 算力退路方案：GCP 扩容不顺时的平台分工

> **2026-11-04 已定（用户确认，见 CLAUDE.md「已定决策」）：锁定 LoRA，算力平台用 AutoDL。** 下文第 1–5 节是做决定前的比较记录，其中 Lambda / Runpod 的分工不再执行；第 6 节迁移验收照常适用，第 9 节记录 AutoDL 的具体情况。
>
> 原记录：2026-11-04 与用户讨论后记录。目标是省钱：预算上限约 100 美元（学生自费，最多稍微超出一点）。

## 1. 什么情况下切换
满足任一条件就按本方案切换：
- GCP 扩容被拒（`GPUS_ALL_REGIONS=4` 或 us-central1 Spot A100=4），而且按需 A100 配额也没批；
- D3 实测发现 Spot A100 抢占太频繁，导致 D4–D8 排不下四组训练。参考：11-03 两次在 2 分钟内被抢占；11-04 的环境配置 probe 一次任务被抢占后重启了 4 次以上。

GCP 批下 ≥2 张 A100 时，留在 GCP，本方案不启用。即使批的是 Spot，也仍可考虑把长训练放到外部平台（见第 2 节原则）。

## 2. 分工
原则：**长时间的正式训练放到按需、不会被抢占的平台；短任务留在 GCP Spot 或 Colab。**

| 工作 | 平台 | 原因 |
|---|---|---|
| D3：C1–C3 实现、单测、0.6B 冒烟、吞吐实测 | GCP Spot（L4 / A100） | 短任务，被抢占了重跑代价小 |
| E0–E3 正式训练 | 外部按需平台，单卡 A100 80GB | 长任务，被抢占一次损失几小时训练 |
| E0–E3 的 dev 选 checkpoint 和封存 test 评测 | 训练一结束就在同一台机器上跑完 | 必须用训练镜像；评测只要几十分钟，省掉再开一次机器的准备时间 |
| B0/B1 | D2 已在 Colab 跑过 dev；D9 在训练镜像里跑封存 test | 和 E0–E3 用同一环境 |
| 副项目 | Colab | 不变 |

约束：
- **E0–E3 四组必须在同一平台、同一显卡型号、同一镜像 digest 上跑**，不能分散到不同平台。
- Colab 的 vLLM 0.33 / torch 2.14 / transformers 5.20 和训练镜像不同，**主实验的正式评测不能放在 Colab**，只能用来做快速检查。
- 结果统一回传到 `gs://ssrl-runs-gqf-2026/runs/<run_id>/`，用 rclone 或服务账号密钥写入；GCS 仍是唯一的结果来源。

## 3. 平台选择（具体价格和有没有现货，切换当天再查）
1. **首选**：整台 VM、能自己跑 Docker 的按需实例（如 Lambda）。`probe_c0.sh` / `smoke_hotpotqa.sh` 等基本不用改，只需设 `DOCKER=docker`。缺点是经常抢不到卡。
2. **备选**：RunPod Secure Cloud（数据中心机器）。租到的是一个容器，需要绕过 `docker exec`，直接跑 `*_inner.sh`，改动小。
3. **不用来跑长训练**：Vast.ai 等个人出租的机器。便宜，但每台机器的质量参差不齐，长任务中途断掉反而更贵。

用户在比较平台时要确认的几项：
- 有没有 A100 80GB / H100 按需现货，能不能租到 2–4 卡；
- 能不能直接用 Docker 镜像，或者给 root 的整台 VM；
- 停机后还收不收磁盘费；
- 出站流量收不收费（回传 checkpoint 用）；
- 按秒计费还是按小时计费。

## 4. 费用估算（D3 实测吞吐后用实测数据替换）
- 4B、LoRA、单卡 A100：每组约 6–10 小时，四组共 25–40 GPU 小时。按每小时 1.2–1.8 美元算，约 40–70 美元。
- 失败重跑预留约 30%。
- 多卡扩展实验（见第 6 节）约 10–20 美元。
- 合计在 100 美元左右。账户是付费账户、没有赠金，GCP Spot 和外部平台花的都是真钱，所以按单价和稳定性比较。

## 5. 省钱做法
1. **新机器的准备工作提前做好**：把检索索引 `index.bin` 和语料上传到 GCS（此前承诺过，还没做），新机器从开机到能开跑控制在 15–20 分钟，不在计费时间里重新建索引。
2. **任务结束自动销毁实例**：沿用 `scripts/gcp/job_entry.sh` 的思路，依次跑训练、评测、同步 GCS，然后销毁实例。只停机不销毁，很多平台仍收磁盘费。
3. **四组串行，一次租用连续跑完**：镜像只拉一次，中途不反复开关机。
4. **checkpoint 只回传 dev 选中的那个**，加最近一个可续训的 checkpoint，中间的不回传。

## 6. 迁移后验收（约 1 小时，正式训练前必须通过）
1. 拉同一个镜像 digest（`env/GPU_ENV.md`），用 0.6B 跑 10 步冒烟，`check_replay.py` 严格检查通过。
2. 在 probe 300 题上跑一次 C0 greedy，EM 应与 `d2_probe_c0_q3-4b-2507_20261103_1100` 的 0.4367 接近（差异超过约 2 个百分点就先查原因）。
3. 跑 `ssrl.checks.logprob_consistency`，结果应和 `d2_logprob_q3-4b-2507_20261103` 同一量级。

三项都通过，D2 的基线和 probe 结论可以继续沿用。显卡从 A100 换成 H100 时，四组都在 H100 上跑，报告中注明硬件。

## 7. 全参还是 LoRA，以及多卡
- **D3 前确定平台，按那个平台能稳定拿到的卡数决定全参还是 LoRA，定了之后不再改**。不要先用 LoRA 跑几组，换平台后又改成全参。
- CLAUDE.md 的单卡规则和 LoRA 锁定源于 GCP 只给一张卡。外部平台的多卡算不算"扩容"，由用户在 D3 决定，决定后写入 CLAUDE.md「已定决策」。
- **单独做一次多卡扩展实验（建议做，不计入主结论）**：租 2–4 张卡几小时，C0 在 1 卡和多卡上各跑约 20 步，记录吞吐、峰值显存、扩展效率、FSDP / vLLM 张量并行的配置和遇到的坑，写成独立的实验卡。用途是简历上的多卡训练经验，不和 E0–E3 的数据混用。若 GCP 批了 4 卡，就直接在 GCP 上做。

## 9. 最终选择：AutoDL（2026-11-04）
比较过的平台（价格为 11-04 当天查询，后续以开机时为准）：
- Runpod（公开 API 查价）：A100 80GB Secure 1.79 美元/卡时、Community 1.19–1.39；A40 / RTX A6000 0.59；L40S 1.09。实时库存需登录，未查到。
- TC2（学校集群）：A40 ×16、L40S ×24（均 48GB），驱动 570（CUDA 12.8），无 Apptainer/Singularity；默认 1 卡 / 30GB 内存 / 6 小时，已发邮件申请更多资源（结果未知）。
- **AutoDL**：RTX PRO 6000 96GB ¥6.98/卡时、A800 80GB NVLink ¥7.98、RTX 6000D 84GB ¥6.46（11-04 网页截图）。价格最低，且常有高端卡放出。

AutoDL 的已知限制和做法：
- 官方 API（第三方 CLI `autodl` 基于它）只能建 **Pro 实例**：h800、pro6000-p、v-48g（4090-48G）、v-48g-350w（3090-48G）、5090-p、v-32g-p、4090D；最多 4 卡；只在西北B区和北京B区。A800、RTX 6000D 是普通实例，只能网页手动开，绑定物理机，多卡要等同一台机器空出足够卡。
- 没有可靠的 Pro 库存接口：`autodl stock` 查的是弹性部署库存，与 Pro 可用量对不上。抢卡做法是按优先级反复 `autodl create`，无货返回退出码 6，不扣费。
- 不能导入外部 Docker 镜像：在官方 PyTorch 基础镜像上按 `env/GPU_ENV.md` 的版本 pip 安装，存成私有镜像。配环境用网页的无卡模式（约 ¥0.1/时，API 不支持）。
- 系统盘 30GB 且只有系统盘进镜像；数据盘内容不进镜像。环境装系统盘，模型、索引、语料放数据盘或文件存储。
- 境内访问不了 GCS：索引和语料从本地 `autodl push` 上传；结果 `autodl pull` 回本地再传 GCS。HF / GitHub 用 `source /etc/network_turbo`。
- 按开机时长计费，与 GPU 是否在用无关：每个实例都设 `--ttl`；跑完立刻关机。连续关机 15 天会被释放。
- 参考：社区博客在 AutoDL RTX 5090（Blackwell）上跑通过 veRL + vLLM（torch 2.8 cu128、vLLM 0.10.2、flash-attn 2.8.3 预编译 wheel），说明 Blackwell 卡可用；我们锁定的版本组合（vLLM 0.12 / torch 2.9）仍需 D3 实测。

D3 环境测试计划（预算 ¥20）：网页无卡模式配环境并存镜像（约 ¥0.5）→ `autodl create --gpu pro6000 --image <私有镜像> --ttl 1h --wait` 单卡验证 vLLM（约 ¥3–7）→ 0.6B LoRA 冒烟 10 步（约 ¥3–5）。多卡实例单独征求用户同意。
